### Root cause

BackdoorBench's ANP applies pruning masks at runtime (as forward hooks
or inline in the defense script's eval loop). When Chinh measured
test_asr=0.00%, BackdoorBench was applying the mask during inference.
But `model_state_dict` saved to the checkpoint does NOT have the mask
multiplied into the actual weight tensors — so loading into a plain
PreActResNet18 skips the mask entirely, and the backdoor is still active.

---

### What Chinh needs to do

After ANP optimization finishes, before saving, permanently apply the
mask to the weights:

```python
# Bake mask into weights permanently
for name, module in model.named_modules():
    if hasattr(module, 'weight') and module.weight is not None:
        mask = ...  # however BackdoorBench exposes the ANP mask
        module.weight.data *= mask

# Verify BEFORE saving — load into fresh model with no hooks:
verify_model = PreActResNet18(num_classes=10)
verify_model.load_state_dict(model.state_dict())
verify_model.eval()
# run eval on bd_test -> ASR must be ~0%
# run eval on clean test -> CA must be ~84%

# Then save:
torch.save({
    'model_state_dict': model.state_dict(),
    'threshold': threshold,
    'test_acc': ca,
    'test_asr': asr,
}, 'data/checkpoints/resnet18_cifar10_badnets_anp.pt')
```

The key verification step: load the saved file into a FRESH
PreActResNet18 (no BackdoorBench hooks active) and eval — ASR must be
~0% without any runtime masks.
