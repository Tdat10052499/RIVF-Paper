## 3. ANP re-run on OUR infected model (fixes C1)

Why the first run was wrong: `attack_result.pt` stores absolute image paths from BackdoorBench's own server (`/workspace2/chenhongrui/bdzoo2_t914/record/...`). Loading it on Kaggle cannot find the images. The 22/09 run instead used a *newly trained* attack (`result_file: badnet_anp_run`). A symlink fixes the paths **without changing the file**, so its SHA-256 still matches.

```bash
cd /kaggle/working
git clone https://github.com/SCLBD/BackdoorBench.git && cd BackdoorBench
pip install -q -r requirements.txt
mkdir -p record data
unzip -q /kaggle/input/<your-dataset>/cifar10_preactresnet18_badnet_0_1.zip -d record/
sha256sum record/cifar10_preactresnet18_badnet_0_1/attack_result.pt
#   must print 6658008230536ccfb76e5234b2ec98effc8f707292ba44734f2e5dc0f9f8a111
mkdir -p /workspace2/chenhongrui
ln -s /kaggle/working/BackdoorBench /workspace2/chenhongrui/bdzoo2_t914
# CIFAR-10 must be at BackdoorBench/data/cifar10 (loader rewrites data_path to <root>/data/...)

python defense/anp.py \
  --result_file cifar10_preactresnet18_badnet_0_1 \
  --yaml_path ./config/defense/anp/cifar10.yaml \
  --dataset cifar10 --random_seed 42 2>&1 | tee anp_v2.log
```

Outputs land in `record/cifar10_preactresnet18_badnet_0_1/defense/anp/`. Keep `checkpoint/mask_values.txt`, `checkpoint/pruning_by_threshold.txt`, `defense_result.pt`, and the log. The **selected threshold** is the one with the lowest test ASR among thresholds whose CA drop is below 10%. Read it from `threshold_df.csv`, or from the last "saving" block in the log.

Then, in the RIVF-Paper repo:

```bash
mkdir -p data/checkpoints/anp_v2
cp <anp dir>/checkpoint/mask_values.txt <anp dir>/defense_result.pt data/checkpoints/anp_v2/
cp anp_v2.log results/raw/anp_v2_defense.log

python scripts/bake_anp_mask.py \
  --infected-ckpt data/checkpoints/resnet18_cifar10_badnets_infected.pt \
  --mask-values   data/checkpoints/anp_v2/mask_values.txt \
  --threshold     <selected threshold> \
  --bb-defense-result data/checkpoints/anp_v2/defense_result.pt \
  --out           data/checkpoints/resnet18_cifar10_badnets_anp_v2.pt
#   must print "Cross-check vs BackdoorBench defense_result: 0 differing tensors"

python scripts/check_lineage.py \
  --a data/checkpoints/resnet18_cifar10_badnets_infected.pt \
```
